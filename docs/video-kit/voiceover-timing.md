# Narration timing

| Time | Narration |
| --- | --- |
| 00–13s | During a memory-care handoff, a note may mention a walker, an aide, and several activities. CareSignal helps reviewers see what the documentation says about one selected walk and check the supporting evidence. |
| 13–18s | This walkthrough uses fictional residents and fixed fixture results for a repeatable demonstration. |
| 18–32s | For Elena’s breakfast walk, the note describes an aide beside her. Her staff-confirmed usual level is independent. CareSignal shows more help than usual. |
| 32–44s | Switch to Ruth. The note stays the same. Her usual level already includes supervision, so her card matches the usual routine. |
| 44–58s | Open the evidence. The relevant words are highlighted beside the source date, version, and confirmed baseline. Both sources remain available so reviewers can check the finding. Code calculates the comparison. |
| 58–75s | Now attach a replacement. It mentions a walker but leaves human help unspecified. The result becomes unclear, the old flag clears, and version one stays in history with its original text. |
| 75–84s | CareSignal also supports Gemini extraction and reproducible evaluation on public synthetic notes. Results and limitations are recorded separately. |
| 84–90s | This project is a prototype and is not medical advice. |
